# raster-algorithms
📋 Описание проекта
Веб-приложение для визуализации и сравнения базовых алгоритмов растеризации отрезков и кривых. Проект включает 6 алгоритмов с возможностью интерактивного построения и анализа временных характеристик.

🎯 Цели проекта
Изучение и реализация базовых алгоритмов растеризации

Сравнение эффективности различных алгоритмов

Создание удобного интерфейса для визуализации

Контейнеризация приложения с использованием Docker

📊 Реализованные алгоритмы
1. Пошаговый алгоритм
Принцип: Вычисление координат по уравнению прямой y = kx + b

Сложность: O(max(|Δx|, |Δy|))

Особенности: Простая реализация, но требует вычислений с плавающей точкой

2. Алгоритм ЦДА (Digital Differential Analyzer)
Принцип: Постепенное увеличение координат с постоянным шагом

Сложность: O(max(|Δx|, |Δy|))

Особенности: Устраняет умножение в цикле, но использует дробные числа

3. Алгоритм Брезенхема (линия)
Принцип: Целочисленная арифметика с параметром ошибки

Сложность: O(max(|Δx|, |Δy|))

Особенности: Только целочисленные операции, высокая скорость

4. Алгоритм Брезенхема (окружность)
Принцип: Построение 1/8 окружности с симметричным отображением

Сложность: O(R)

Особенности: Эффективное построение окружностей без дробных операций

5. Алгоритм Кастла-Питвея
Принцип: Модификация Брезенхема с двумя параметрами ошибки

Сложность: O(max(|Δx|, |Δy|))

Особенности: Более равномерное распределение пикселей для малых углов

6. Алгоритм Ву (сглаживание)
Принцип: Антиалиасинг через суперсэмплинг и интенсивность пикселей

Сложность: O(max(|Δx|, |Δy|))

Особенности: Устранение лестничного эффекта, сглаженные линии

🛠 Технологический стек
Frontend: HTML5, CSS3, JavaScript (ES6+)

Графика: Canvas API для отрисовки сетки и пикселей

Контейнеризация: Docker, nginx

Хостинг: Docker Hub для распространения образа

🚀 Запуск приложения
Локальный запуск (разработка)
bash
# Открыть index.html в браузере
# или использовать Live Server в VS Code
Запуск через Docker
bash
# Сборка образа
docker build -t raster-algorithms .

# Запуск контейнера
docker run -p 8080:80 raster-algorithms

# Доступ: http://localhost:8080
Запуск из Docker Hub
bash
docker run -p 8080:80 alxnrayyy/raster-algorithms:latest

🎮 Использование интерфейса
Выбор алгоритма - из выпадающего списка

Ввод координат - числовые поля или рисование мышью на канвасе

Настройка сетки - масштаб и размер ячейки

Построение - кнопка "Построить" для визуализации

Анализ - просмотр времени выполнения и деталей вычислений

📈 Особенности реализации
Система координат - декартова с центром в (0,0)

Целочисленные координаты - привязка к узлам дискретной сетки

Временные характеристики - замер времени выполнения для каждого алгоритма

Интерактивность - рисование мышью, динамическое обновление

Адаптивность - интерфейс работает на разных разрешениях экрана
